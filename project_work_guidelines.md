# Project Work Structure

## Project Structure

1. Description of the dataset
2. Data cleaning (if needed)
3. Exploratory analysis
4. Main analysis: objective and methods adopted
5. Preview/summary of the results
6. Detailed results
7. Conclusions

The project work is composed of two parts:

- **A. The presentation**
- **B. Supplementary materials and methods**

## A. The Presentation

- The presentation should last 15 minutes.
- All group members must present one part of the project.
- Slides must be in PowerPoint or PDF format.
- The presentation must contain no more than 15 slides.

## B. Supplementary Materials and Methods

- **Output of the elaboration:** Python Jupyter Notebook.
- The notebook must be technical but sufficiently self-explanatory to be readable and comprehensible, with comments where appropriate.
- Tables, conclusions, and analyses contained in the presentation must refer to the supplementary materials.
- The size and level of detail of Part B depend on the type of project. There are no specific requirements; it must be appropriately sized.

## General Requirements

- The discussion of the project work must be organized by each group with the teachers.
- Materials must be sent a few days before the exam.
- Scripts and code may be run by the teachers, so submit clean and working code only.
- Only methods, models, and packages covered in the course are allowed.
- Students must justify their project choices in the presentation and during the discussion.
- Real-time experiments with the code may be requested during the presentation, so keep the code ready to run during the discussion.

## Exam and Assessment Conditions

- The project can be presented only when all group members have passed the written exam.
- If all members have passed the written exam, they can present the project even if one member wants to retake the written exam at a later session to improve their grade.
- The project work is mandatory.
- If the quality of the project is too poor, it must be improved to pass the overall exam.
- If the quality of the project is sufficiently good, the group members will receive a bonus on the final grade.
